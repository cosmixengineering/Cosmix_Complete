1. Executive Summary & Project Overview

Cosmix ERP is an enterprise-grade, distributed resource planning system specifically designed for heavy field engineering, telecommunications infrastructure, site project operations, and distributed workforce logistics. The software coordinates multi-site civil and fiber operations across Pakistan, where strict attendance verification, geo-fenced boundaries, biometric face verification, duty allowance accounting, and immutable payroll handoffs are critical.

The software architecture enforces a Zero-Trust Security Paradigm combined with Maker-Checker (Dual-Control) governance. High-consequence financial and human resource operations—including employee hiring, shift assignments, overtime approvals, advance salary disbursement, month closure locks, and bank payroll handoffs—cannot be finalized by a single individual.

📌 Core Value Proposition & Operational Impact

  • Complete Elimination of Proxy Attendance: Dual biometric GPS geofence + AI face verification prevents ghost workers.
  • Automated Overtime & Allowance Calculation: Shift engines automatically evaluate 13h meal stipends (PKR 400), dinner claims, and PKR 1,000/day outstation duty.
  • Cryptographically Sealed Payroll Handoffs: Month closures freeze attendance data into immutable digests, generating standard Bank Advice CSV files for 1-Link clearing.
  • Live Fleet & Fuel Price Governance: Seamless tracking of corporate vehicles with real-time PSO/Shell pump price feeds in PKR.
  • Comprehensive 14-Stream HR Reporting: Full audit readiness for labor audits, tax authorities, and client verification.

3. Backend Deep-Dive: .NET 10 Clean Architecture

The backend is constructed strictly according to Clean Architecture and Domain-Driven Design (DDD) principles. Dependencies flow strictly inward toward the domain layer:

  • Domain Layer (Cosmix.Domain): Defines core business entities, aggregates, and value objects with zero external dependencies. Houses aggregates: Employee, AttendanceLog, ShiftPolicy, AllowanceClaim, AdvanceLoan, and PayrollHandoffBatch.
  • Application Layer (Cosmix.Application): Encapsulates business use cases, orchestrations, security validations, and service contracts. Houses AttendanceProcessingService, PayrollHandoffService, and MonthLockCoverage.
  • Infrastructure Layer (Cosmix.Infrastructure): Implements interfaces defined in the domain and application layers. Manages EF Core DbContext, SQL Server schema configurations, PrivateFileStore, and DPAPI key management.
  • Presentation API Layer (Cosmix.Api): RESTful HTTP endpoints, route controllers, authentication middlewares, OpenAPI documentation, rate limiting, and LocalTesting environment harnesses.
