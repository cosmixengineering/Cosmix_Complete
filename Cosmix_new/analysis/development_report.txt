HMS ERP / FSM SYSTEM
Comprehensive Technical Audit, Gap Analysis & Developer Action Roadmap
1. Executive Summary & High-Level System Status
Following a comprehensive deep-dive code audit conducted by 7 specialized AI agents across all 70 sections of the HMS ERP/FSM SRS, this report establishes the exact status of the platform, the architectural foundation already built inside the NOIR base, and an unambiguous, step-by-step developer roadmap for the next 5 months.
2. Honest Breakdown: Backend vs Frontend Completion & Gap Analysis
A critical objective of this audit is total transparency regarding what is completed versus what is missing. The system cannot be evaluated with a single broad percentage; Backend and Frontend layers are at distinctly different stages of maturity.
2.1 Backend Deep Breakdown (.NET 10 Clean Architecture) — Completion: 45% - 50%
The backend foundation is structurally sound. Developers do not need to invent database tables or invent routing patterns from scratch. However, the system currently consists of data stores and endpoints rather than an autonomous enterprise execution pipeline.
2.2 Frontend Deep Breakdown (React 19 / TypeScript / Vite) — Completion: 20% - 25%
NOIR contains 56 robust React pages for platform administration, user access, and CRM. However, NONE of the 23 specialized ERP panels have frontend screens yet. The backend APIs exist, but frontend developers must build the corresponding UI views. The audit identified exactly 34 Pages and 25 Modals/Drawers that must be coded in React 19.

4. Immediate Developer Action Plan (Sprint 0 - Office Kickoff)
Upon reaching the office, developers should NOT begin writing ad-hoc frontend code immediately. They must execute the following sequential setup steps to stabilize the backend and database:
• Step 1: Execute EF Core Migration: Generate and apply the comprehensive migration to create all tables for the 23 panels:
dotnet ef migrations add AddCompleteErpAndFsmModules --project src/NOIR.Infrastructure --startup-project src/NOIR.Web
dotnet ef database update --project src/NOIR.Infrastructure --startup-project src/NOIR.Web
• Step 2: Seed Granular Permissions: Register missing permissions in NOIR.Domain.Common.Permissions.cs (e.g. FsmRead, FsmManage, ComplaintsRead, QaRead, ProcurementRead, InvoicingRead) and run RoleSeeder so platform admins can access the endpoints.
• Step 3: Run Solution & Verify Scalar API Docs: Execute 'dotnet run --project src/NOIR.Web' and navigate to http://localhost:5000/api/docs to inspect and test all Minimal API endpoints in the interactive Scalar documentation interface.
• Step 4: Refactor Minimal APIs to Wolverine CQRS Handlers: Move direct DbContext operations in Procurement, Fulfillment, Invoicing, Commercial, Intake, Engineering, and QA into NOIR.Application/Features/<Domain>/Commands and Queries with FluentValidation validators.
5. Realistic 5-Month Roadmap & Monthly Deliverables
Month 1: Foundation, Estimation (BOQ), Commercial & Procurement
• Backend: Stabilize EF migrations, refactor CQRS handlers, create CustomerPurchaseOrderItem.
• Frontend: Build BOQ List & BOQ Builder workspace; build Customer PO vs Quote Diff Viewer; build Supplier & PO generator screens.
• Deliverable: Estimators can create BOQs, procurement can issue POs, and commercial managers can reconcile Customer POs against quotations.
Month 2: Stores, Material Management & Manufacturing (BOM & Work Orders)
• Backend: Implement Store aggregate (Physical/Virtual, Local/Int'l) and multi-location StoreInventory ledger; link BOMs to production orders; wire material consumption.
• Frontend: Build Multi-store Stock Availability matrix, GRN receiving desk, Stock Transfer grid, BOM tree designer, and Production Order tracker.
• Deliverable: Complete inward receipt, stock movement, dual-store routing, and manufacturing assembly workflows.
Month 3: Fulfillment, Delivery OTP & Field Service Management (FSM)
• Backend: Implement DeliveryAdvice aggregate; build secure SMS OTP generator; build Geolocation proximity verifier (<=200m) and Red Zone breach alert engine.
• Frontend: Build Delivery Challan print/dispatch screens; build Mobile PWA for Field Technicians with 1-tap Google Maps directions, material usage entry, and customer OTP sign-off modal.
• Deliverable: Closed-loop field installation, delivery with customer OTP proof, and technician tracking.
Month 4: Accounts, Invoicing, After-Sales & Helpdesk
• Backend: Build Vendor Bills (AP) and 3-way matching; implement Auto-Calculator service (GST & WHT deductions); wire automated GL posting triggers; build SLA escalation job for complaints/tickets.
• Frontend: Build Sales Invoicing builder, Payment Settlement modal, Chart of Accounts tree, Complaints resolution desk, and Helpdesk conversation stream.
• Deliverable: Double-entry financial books, customer billing, vendor payments, and customer support portal.
Month 5: AI Engine, Executive Intelligence, Reports & UAT
• Backend: Integrate Semantic Kernel LLM client; deploy MailKit IMAP worker for auto-intake; build AI Inbox classifier and draft responder; build Predictive Inventory forecasting.
• Frontend: Deploy floating AI Assistant widget; build Executive CEO KPI Dashboard; generate Trial Balance and AR/AP aging reports.
• Deliverable: End-to-end UAT sign-off, production deployment, and go-live.
