exact-location deny so the official /admin/user/register handler receives the
request through the existing admin proxy. Existing LAN restrictions, request/rate

Demo endpoint
-------------
/admin/user/demo/model returns the native CompreFace404 JSON with message
"The Demo model is not available any more!". The official1.2.0 UserController only
offers this demo key while the initial demo user exists. First owner registration
replaces that demo user. The UI DemoEffects explicitly catches this response and
marks the optional demo unavailable. This is expected after owner provisioning;
it does not mean deployed CompreFace or ONNX models are missing/down, and it is
not the cause of sign-up failure. No success response or production key is
fabricated/exposed to suppress that browser console entry.
