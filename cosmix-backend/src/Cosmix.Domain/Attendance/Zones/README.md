# Zones domain

Source: SRS 6.3; ZONE-001 to ZONE-010.

Configurable circle/polygon zones, versions, employee/role/team/site assignments and individual exceptions. Keep zone events separate from attendance; no automatic payroll/discipline. Limit monitoring to duty windows and protect confidential reasons.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
