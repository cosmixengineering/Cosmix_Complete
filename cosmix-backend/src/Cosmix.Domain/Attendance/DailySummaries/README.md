# DailySummaries domain

Source: ATT-009, SHIFT-003, SRS 8.

Derived worked/payable minutes, late/absence and overtime with policy/calculation version. Recalculation never edits raw evidence or locked periods silently.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
