# Overtime domain

Source: SRS 8.3; OT-001 to OT-005; MD-007.

Eligibility, requests, work intervals/site/job, evidence, independent approval and payroll-ready amounts. Do not invent hourly rates or assume travel automatically earns overtime.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
