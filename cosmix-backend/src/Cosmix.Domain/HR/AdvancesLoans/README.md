# AdvancesLoans domain

Source: SRS 11, 12 and 18.

Employee advance/loan requests, approval, repayment history and payroll handoff. Management must confirm detailed limits, repayment and approval rules before coding calculations.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
