# VehicleFuel domain

Source: SRS 10.2; VEH-001 to VEH-009.

Work trips/travel, approved mileage, fuel claims, motorcycle maintenance, workshop history, vehicle custody, issue/return condition and accident evidence. Policies and eligibility must be effective-dated.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
