# Leaves domain

Source: SRS 9; LEAVE-001 to LEAVE-013.

Types, fiscal-year balances, requests, medical/exam evidence, approval, cancellation, encashment and scoped team calendar. Coordinate approved leave with attendance; never bypass the shared approval rules.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
