# PayrollHandoff domain

Source: SRS 12, 15, AC-007; MD-014.

Consume locked approved attendance, overtime, allowances and deductions with trace IDs. Accounts cannot edit raw punches. Salary self-service is scoped; no automatic bank disbursement or invented finance ledger.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
