# EmployeeSelfService domain

Source: SRS 11; MOB-007 and MOB-008.

Own profile/documents, salary/deductions and request history. Derive employee identity from the authenticated account, not a trusted client employee ID. React Native is not an HR administration panel.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
