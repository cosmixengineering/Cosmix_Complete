# Compensation domain

Source: SRS 5, ROLE-004, HR-004.

Restricted effective-dated salary/wage and bank information, separate from general employee DTOs. Sensitive changes need approval and audit. Do not expose these fields by default.

Add entities, approved value objects and pure business rules here as this feature is implemented. No EF Core, controllers or external SDK calls. This folder is a planned location, not an implemented data model.
