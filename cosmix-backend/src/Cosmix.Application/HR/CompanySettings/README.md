# Company settings

The explicit company/head-office configuration and dated site jurisdiction timeline reuse existing
Branch, City and Site masters. Current SuperAdmin plus the separately granted manage permission is
required for every mutation. Profile rowversions, retained corrections, organization history/audit
and exact retries protect changes.

The internal payroll source resolves only the site's dated version and never infers jurisdiction
from head-office or city text. Configuration does not certify legal applicability; legal review
remains required. See [scope and executed checks](../../../../docs/attendance-completion/Company-Settings.md).
