## Current regression execution

`EmployeeAuthorityExpiryTests.cs` adds 26 cases: 16 read/write/replay/try-replay combinations of session/grant expiry during initial role IO or audit save, two unknown-timing denials, four valid controls, and four same-assignment fixed Admin review cases. Two additional `LocationConsentTests` cases cover session revocation during the audit save for status reads and acceptance. The original `EmployeeOperation` validates only at transaction entry, does not filter returned grants by retained `IsEffectiveAt`, and has no completion check after action/file/audit IO. This differs from the existing `AttendanceOperation` completion pattern. The original consent self operation rechecks before its audit save but not afterward.

At document creation, the new regression is awaiting the coordinator's RED run; no repair pass or complete-suite pass is claimed here. The coordinator will append exact build/test output, counts and artifact paths after execution. No shared migration/startup change is required by this regression.
